# WifiSec

> Go 编写的专业无线安全测试工具：帧注入跑在 ESP8266/ESP32 协处理器上，宿主机零依赖，macOS / Linux / Windows / Termux 全平台免 root。在线密码爆破支持无设备回落本机网卡，命中即停输出完整凭证。

WifiSec（无线安全审计工具）是哪吒网络安全出品的开源 WiFi 渗透测试与口令强度评估框架，采用 Hexagonal Architecture（六边形架构），Go 1.26+ 纯血实现，核心链路零 CGO。它把传统无线审计里最难缠的三件事——**root 权限、monitor 模式驱动、平台差异**——全部下沉到一块约十元的 ESP 开发板上：deauth 帧注入与关联尝试跑在板载射频，宿主机只经 USB 串口收发协议帧。

## 为什么选择 WifiSec

- **免 root 全平台覆盖**：macOS 无公开帧注入 API、Windows 要 Npcap、Android 10+ 禁止编程关联——这些平台限制被 ESP 协处理器路径一次性绕开，一条 USB 线全解决
- **双路径密码爆破**：插板子时关联尝试跑在 ESP 射频上不碰本机网络；无设备时自动回落本机网卡（macOS networksetup / Linux nmcli / Windows netsh），macOS 侧采用两段式判定杜绝「受理了但没连上」的假命中
- **命中即停凭证块**：爆破逐次尝试带耗时输出，命中立即终止并打印 SSID / BSSID / 密码 / 尝试序数 / 总耗时的完整凭证块；BSSID 按路径分级取证，macOS 系统脱敏时如实标注不猜不编
- **工业级串口协议**：小端帧格式双向魔数防方向错乱、复位时序强制 Flash 启动、74880 启动噪声逐字节重同步、能力位图协商（bit0 = 5GHz）不猜板型
- **一键自更新**：`wifisec upgrade` 直接从 GitHub Releases 拉取对应平台产物原地原子替换，版本号与 git tag 严格对齐
- **生产级工程质量**：表驱动测试覆盖协议编解码与解析逻辑、五平台交叉编译 CI、Conventional Commits + githooks 强制校验、串口占用进程点名诊断

## 命令一览

- `wifisec list`：无线接口枚举与周边网络扫描（macOS CoreWLAN / Linux iw / Windows netsh），同名 SSID 多 AP 全部列出
- `wifisec serial`：USB 串口设备发现，VID:PID 芯片对照（CH340 / CP2102 / FT232 / CH9102），占用进程点名
- `wifisec deauth <ssid|bssid> [串口]`：对目标持续发送 802.11 deauthentication 帧，同名多 AP 轮流切信道全命中，Ctrl-C 停止并输出统计
- `wifisec jam <ssid|all|bssid> [串口]`：deauth + disassoc 双帧全频段干扰，覆盖只过滤 deauth 但不过滤 disassoc 的客户端；`jam all` 扫描全部可见 AP 逐个打击，200ms 间隔，Ctrl-C 停止并输出统计
- `wifisec brute <ssid|bssid> with-pass: <字典> [串口]`：在线密码字典爆破，ESP 协处理器与本机网卡双路径，命中即停输出凭证块
- `wifisec clone <ssid>:<密码> up [nokick] [串口]`：热点克隆（Evil Twin），同名同密码 SoftAP + 默认 200ms 节奏 kick 驱赶真实 AP 客户端，设备接入/离开实时打印；ESP 路径 AP+STA 双模，无设备回落 Linux hostapd（需 root，kick 需第二块网卡）
- `wifisec clone down [串口]`：停止固件上的克隆热点，恢复 STA 模式
- `wifisec devices [网卡名]`：局域网设备发现，TCP 探针刷 ARP + 系统邻居表交叉（Linux /proc/net/arp、macOS arp -an、Windows arp -a），输出 IP/MAC/主机名/网关角色，四平台免 root
- `wifisec sniff [--spoof] [--targets ip1,ip2] [--iface 网卡]`：bettercap 风格实时嗅探（Linux AF_PACKET、macOS BPF、Windows Npcap，需 root/管理员）——被动模式直读网卡帧，DNS 查询 / HTTP 请求 / TLS SNI 实时标注 + 40 行/秒限速 + 协议分布统计；`--spoof` 叠加 ARP 欺骗 MITM：双向 1s 毒化 + who-has 即时应答 + IP 转发与 ICMP redirect 压制（Linux procfs / macOS sysctl），退出时按启动前备份以真实 MAC 重发 5 轮恢复帧完整还原；Windows 欺骗因 IPEnableRouter 无法即开即还而明确拒绝，被动嗅探不受影响
- `wifisec scan_ports <目标> [端口规格]`：nmap 风格 TCP connect 扫描（200 并发、1.5s 超时），open/closed/filtered 三态判定 + 被动 banner / HTTP HEAD 抓取，支持 top（47 端口）/all（1-1000）/逗号列表/区间，四平台免 root
- `wifisec bind [--port N] [--token 令牌] [--timeout 秒]`：横向移动被控端——bind shell 监听 TCP，HMAC-SHA256 挑战应答认证（令牌不落网），空令牌自动生成随机令牌并打印；命令经 /bin/sh -c（Windows cmd /C）解释，stdout/stderr 实时回传，超时击杀回退出码 124
- `wifisec <ip> bash [--token 令牌]`：横向移动控制端——IP 开头自动路由进交互 shell（等价 `shell <ip> bash`），`wifisec <ip> <命令>` 单命令一步执行且远端退出码映射本地；令牌亦可经 WIFISEC_TOKEN 环境变量传递
- `wifisec get_packet [网卡] [秒] [文件]`：连接态网卡抓包（Linux/Android AF_PACKET、macOS BPF、Windows Npcap），终端 40 行/秒限速摘要（折叠屏显不丢帧），全帧写纯 Go 手写 pcap（DLT 1），Wireshark/tcpdump 直读，Ctrl-C 收尾；`--eapol` 实时分析 EAPOL 握手并按 `--bssid`/`--ssid` 过滤，`--pmkid` 主动会话与抓包共存（Linux/Windows）
- `wifisec pmkid <ssid|bssid> [网卡] [-o out.22000] [--ssid 名称] [--attempts N] [--json]`：PMKID 主动获取——假客户端发 Auth+Assoc，从 RSN IE 抽 PMKID，免客户端、免踢人、不怕 802.11w；AKM 非 PSK 明确拒绝，随机 STA MAC 重试退避，产出 hashcat 22000 行
- `wifisec extract capture.pcap [--hashcat out.22000] [--pmkid out.16800] [--bssid xx] [--ssid 名称] [--json]`：pcap 离线提取——逐 AP 统计完整握手数 / PMKID 有无 / 各帧合法性，同一 BSSID 双证据时优先 PMKID，隐藏 SSID 恢复不了拒绝产出（绝不空 salt 算 PBKDF2）
- `wifisec ids [SSID] [网卡] [秒数]`：无线入侵检测，扫描差分（伪造AP/KARMA/加密降级/弱加密与开放网络盘点，免 root）+ 帧级监测（deauth/解除关联风暴、信标泛洪，Linux monitor VIF / macOS BPF，不可用时如实降级），可锁定单个 SSID 做目标值守（BSSID 解析 + 跳频钉信道），告警按严重/警告/提示分级带证据，防御视角
- `wifisec heatmap [SSID] [平面图.txt]`：纯终端 TUI 站点勘测热力图，走点位按空格采样 RSSI 钉入网格，未采样格按 IDW（1/d² 反距离加权）插值着色（超半径留白不编造），支持文本平面图叠加、最多 9 个 AP 目标 Tab 切换各自独立网格、加密风险角标，结束自动落盘 JSON 并给出 AP 方位估计，五级色阶（≥-50 绿 / -60 黄绿 / -70 金 / -80 橙 / 更弱或缺数据红）
- `wifisec upgrade`：从 GitHub Releases 下载最新版并原地替换当前二进制
- `wifisec help`：用法总览（含版本信息，版本与 GitHub Release tag 一致）

## 快速开始

```bash
go install github.com/ctkqiang/wifisec/cmd/wifisec@latest
```

或从 GitHub Releases 下载预编译产物：macOS `.app` bundle（含定位授权）、Linux amd64/arm64 单文件、Android Termux arm64 免 Go 环境、Windows amd64 单文件可执行。

## 技术架构

- 语言：Go 1.26+，核心链路零 CGO（macOS 扫描经 CoreWLAN Objective-C 桥接）
- 架构：Hexagonal Architecture，应用层只依赖 frameWriter / channelSetter 等端口，平台能力收敛在 adapter 层
- 协处理器：ESP8266 / ESP32 全系一份固件源码编译期条件分支，仅 ESP32-C5 具备 5GHz 能力
- 串口协议：`[魔数][cmd][len_lo][len_hi][payload]` 小端帧；主机→ESP 魔数 0xA5，ESP→主机 魔数 0x5A
- 注入原语：`wifi_send_pkt_freedom`（ESP8266）/ `esp_wifi_80211_tx`（ESP32）
- 关联命令：CMD_ASSOC 0x03，payload 为 ssidLen + ssid + passLen + password，固件侧 12 秒应答窗口
- 克隆命令：CMD_CLONE 0x05（op + channel + ssidLen + ssid + passLen + password，op 1=up 0=down）与 CMD_CLONE_STATUS 0x06（在线设备 count + MAC 列表），克隆结果回传 result + apMAC
- 版本注入：ldflags -X BuildVersion（Makefile 构建）→ debug.ReadBuildInfo（go install）→ dev 三级回退
